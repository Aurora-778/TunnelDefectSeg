Metric glossary 中文说明

      

        

          
风险等级
由缺陷面积、骨架长度、连通域数量和不确定性综合得到，分为 none / low / medium / high。

          
风险分
风险等级背后的连续分值。分值越高，代表病害形态或模型不确定性越需要关注。

          
缺陷像素
融合预测 mask 中非背景类别的像素总数，反映检测到的病害区域大小。

          
Review
当缺陷区不确定性偏高，系统会给出 YES，表示建议人工检查该图。

          
增强候选
指 SegFormer 对原图、水平翻转图等输入姿态输出的概率预测，先对齐再融合。

          
Uncertainty
由概率熵或 TTA 概率计算，颜色越热表示模型越拿不准。

          
高不确定缺陷占比
缺陷像素中不确定性超过阈值的比例，是复核建议的重要依据。

          
连通域
互相分离的缺陷块数量。数量多可能表示破碎、散裂或误检碎片。

          
骨架长度
把缺陷区域细化成中心线后的长度，适合描述裂缝类长条形病害。

          
mIoU
预测 mask 与人工标注 GT 的平均交并比。没有 GT 的自选图片显示 N/A。

          
Fused mask
由多姿态概率平均后再 argmax 得到，用来减少单次推理的偶然波动。

          
Self IoU
只比较 Single mask 和 Fused mask 的一致性，可用于无 GT 图片，但不能代表真实精度。

          
Disagreement
由多姿态预测差异计算，颜色越热表示候选预测分歧越大。

          
Overlay
把融合 mask 叠加到原图上，用于直观看缺陷位置和覆盖范围。
