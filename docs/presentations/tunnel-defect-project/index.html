开头直接说明项目范围：不是只做一个分割模型，而是做了从数据、训练、增强、评估到 Web 展示的一套闭环。重点突出两个层次：SegFormer 提升原始分割质量，增强模块提升输出可靠性和可解释性。

problem definition

要解决的问题：模型预测能用，但不够可信。

形态容易失真

折角、细长、局部断裂病害容易被预测成规整块状区域。

mask quality

单张图片没有 GT

用户拖入图片时无法计算真实 mIoU，不能用伪指标误导展示。

no ground truth

缺少复核依据

只输出最终 mask 不够，老师或工程人员需要知道风险来自哪里。

review evidence
项目目标：在更强分割骨干之上，增加可解释的后处理增强和风险提示，而不是只追求单个最终 mask。
design target: better mask source + inspectable reliability layer
这一页解释为什么要做增强模块。老师通常会问：为什么不只是换模型？回答是：换模型解决原始分割能力，增强模块解决自选图片场景中的可靠展示、复核提示和专利差异化。

enhancement module

增强模块：不是盲目融合，而是自适应选择。

decision_loop.py
input: single_mask, fused_mask, uncertainty, disagreement

measure self_iou, foreground_shrinkage, components
detect harmful fusion or unstable boundary
select single / fused / hybrid
measure skeleton and morphology
score risk with explainable reasons

output: selected_mask + evidence report

single

保留单次预测中可能被融合抹掉的小缺陷。

fused

当多次预测稳定一致时，采用更稳的融合输出。

hybrid

融合 mask 加回满足门控条件的可信缺陷像素。

adaptive_fusion.py · morphology_adapter.py · risk_adapter.py
这一页讲增强模块工作方式。关键词是 harmful fusion detection、adaptive output selection、explainable review evidence。它不是简单 TTA，也不是单纯 skeleton，而是一个有顺序的决策闭环。

innovation points

创新点：围绕“可信输出”组织，而不是堆组件。

01

有害融合识别

通过 self IoU、前景缩减、uncertainty、disagreement 判断 TTA fused 是否正在损伤小缺陷。

02

自适应 mask 选择

在 single、fused、hybrid 之间选择输出，减少固定融合导致的前景丢失。

03

形态量化复核

对 selected mask 计算面积、连通域、骨架长度、方向等指标，支持可解释风险提示。

04

GT-aware 展示边界

有 GT 才算真实 mIoU；无 GT 上传只展示 self-consistency、morphology、risk，避免伪精度。

可申请方向：一种面向隧道病害分割的置信感知自适应输出选择与复核提示方法。
claim: ordered decision loop + measurable review evidence
这一页可以直接回答“创新点是什么”。不要说发明了 SegFormer、TTA 或 entropy uncertainty，这些都是已有方法。差异化在于针对隧道病害的决策流程和证据输出。

patent-oriented framing

专利表达：方法链条比单个组件更关键。

建议主张

  • 面向隧道病害分割的置信感知 adaptive selection 方法
  • 基于前景缩减和 self-consistency 的 harmful fusion detection
  • 融合 morphology 与 uncertainty 的人工复核优先级输出
  • 区分 GT accuracy 与 no-GT reliability signals 的展示机制

不建议过度主张

  • 不说发明 SegFormer
  • 不说发明 TTA / entropy uncertainty / skeletonization
  • 不说 selected mIoU 永远超过 single
  • 不把图像复核建议说成结构安全诊断
defensible novelty: decision order + tunnel-defect evidence package
老师如果关心专利，核心回答是：我们不把已知模型或已知算子包装成创新，而是把它们组织成针对隧道病害的可验证决策链条，并有数据支撑。
